# HLD Delivery Framework for Integration Rounds

*Week 1. The structure to follow in every design round and mock. The general HLD version is already in `Core Building Blocks.md` section 0; this note adapts it for integration, SE and FDE rounds, where there is usually a customer in the story.*

---

## Outline (to fill in)

1. **Requirements:** functional, non-functional, and the customer's constraints (their stack, security team, deadline, what they can change).
2. **Core entities:** the nouns, and which system owns each one (ours or theirs).
3. **API and events:** requests in, webhooks out. See `API Design.md`.
4. **High-level design:** a simple working diagram across both systems.
5. **Deep dives:** failures, retries, idempotency, ordering, auth, monitoring.
6. **What the customer owns:** what they build, run and monitor.
7. **Rollout:** sandbox, pilot, migration, cut-over.
